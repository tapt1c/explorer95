# Следующие задачи Explorer95

Список сохранён по запросу пользователя для следующего рабочего захода после
сброса лимитов. Реализация этих пунктов пока не начата. Порядок пунктов — как
в запросе пользователя; все изменения должны сохранять поддержку Windows 95
и классическое оформление.

## 1. Drag and Drop

- Добавить Drag and Drop операций с файлами и папками на рабочем столе
  Explorer95 и в файловом Проводнике, включая перенос между ними.
- Учесть существующее свободное перемещение значков рабочего стола: файловые
  операции должны сосуществовать с ручной раскладкой, её сохранением и сеткой.
- Сохранить штатные подтверждения и отмену файловых операций Windows 95.

## 2. Кнопки задач в стиле Windows 7

- Добавить в настройки панели задач выбор вида кнопок/плиток задач в духе
  Windows 7, сохраняя существующий классический вид как вариант.
- Поддержать этот вид как с группировкой окон, так и без группировки.
- Использовать общую вкладку Taskbar и сохранять выбор после перезапуска.

## 3. Порядок правой колонки меню Пуск

Установить следующий порядок сверху вниз; отсутствующие пункты добавить:

1. My Documents
2. Recent Documents
3. Favorites
4. My Computer
5. Network Neighborhood

**Разделитель**

6. Control Panel
7. Printers
8. Command Prompt

**Разделитель**

9. Help
10. Find
11. Run

Сохранить пользовательские переключатели видимости пунктов и проверку
доступности сети. Разделители должны учитывать скрытые пункты и пустые группы.

## 4. Служебные символы Marlett

- Перенести стрелки вроде `>` и аналогичные служебные символы меню Пуск
  и панели задач на соответствующие глифы шрифта Marlett.
- Сохранить совместимость с Windows 95 и запасной способ отрисовки,
  если нужный шрифт недоступен.

## Проверки при реализации

Следовать пропорциональному выбору проверок из AGENTS.md. Для этого сохранения
списка достаточно просмотра diff; сборка EXE и новый бинарный релиз не нужны.
