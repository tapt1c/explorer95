# Explorer95

Любительская оболочка в духе Windows XP для Windows 95: классическое оформление,
рабочий стол, панель задач, двухколоночный «Пуск» и отдельные окна Проводника.
Luna не используется. Цвета, шрифты и системные значки берутся из установленной Windows.

Проект остаётся экспериментальным. Новую версию сначала проверяйте в виртуальной
машине: реальная загрузка Windows 95 с Explorer95 в качестве shell здесь ещё не проверена.

## Что реализовано

- **Рабочий стол:** системное представление `IShellView` из Shell32, значки,
  открытие объектов, выделение, перетаскивание и системные контекстные меню.
  Поддерживаются цвет фона и BMP-обои из параметров Windows, центрирование и мозаика.
- **Контекстное меню рабочего стола:** команды установленной Shell32, включая
  доступные в ней команды буфера обмена и свойства; дополнительно — упорядочивание,
  создание папки/текстового документа и подменю Explorer95 с настройками панели.
  Состав и язык системных команд зависят от версии Shell32. «Свойства» Windows
  позволяют менять оформление и фон средствами самой Windows 95.
- **Панель задач:** кнопки окон, восстановление и сворачивание, системное меню окна
  по правому щелчку, группировка окон одного процесса, часы и «Показать рабочий стол»
  с восстановлением ранее свёрнутых этой командой окон.
- **Настройки панели:** четыре стороны экрана, перетаскивание незаблокированной
  панели к краю, изменение толщины с привязкой к трём размерам, одна–три строки,
  ширина кнопок, блокировка, автоскрытие, положение поверх окон, часы,
  быстрый запуск, размер его значков и скрытие неактивных уведомлений.
  Настройки сохраняются между запусками.
- **Быстрый запуск:** значки программ/ярлыков из папки Quick Launch; добавление
  перетаскиванием файла на панель задач создаёт ярлык, исходный файл сохраняется.
  Для дополнительных элементов можно открыть саму папку через меню панели.
- **Трей:** приём базового ANSI-протокола уведомлений Windows 95: `NIM_ADD`,
  `NIM_MODIFY`, `NIM_DELETE`, значки, подсказки и обратные сообщения мыши приложению.
  Скрытые и не поместившиеся уведомления доступны через кнопку `>`.
- **Пуск:** заголовок с именем пользователя, Explorer и MS-DOS Prompt, семь последних
  программ слева, дерево All Programs с вложенными папками; справа — документы,
  недавние документы, компьютер, сеть, панель управления, принтеры, помощь, поиск и Run.
  Внизу — выход из Explorer95, завершение сеанса и выключение с подтверждением.
- **История программ:** успешные запуски через Run, файловые окна, меню программ,
  быстрый запуск и файловые значки нашего рабочего стола. Аргументы Run сохраняются.
  Это история запусков через Explorer95, а не глобальное наблюдение за всеми процессами.
- **Окна:** файловый браузер с адресом, дисками, значками, типами и размерами;
  системные виртуальные папки (например, «Мой компьютер» и панель управления)
  открываются в отдельных окнах с настоящим представлением Shell32.

## Два режима работы

При обычном запуске Explorer95 работает рядом со штатным Explorer, не завершает его
процесс и не меняет загрузочную оболочку. Панель регистрируется как appbar и
резервирует свою рабочую область, чтобы развёрнутые окна её учитывали.

Если штатной панели `Shell_TrayWnd` нет, Explorer95 работает как основная оболочка:
резервирует рабочую область самостоятельно и принимает уведомления приложений через
совместимое окно `Shell_TrayWnd`. При выходе рабочая область восстанавливается.

В режиме рядом со штатным Explorer обычные `Shell_NotifyIcon`-уведомления остаются
в его трее. Перехват чужой панели не производится. Трей Explorer95 рассчитан на
базовый ANSI-протокол Windows 95, а не на расширенные протоколы XP/современной Windows,
GUID, всплывающие баллоны или собственный формат Wine. Сквозная совместимость с
реальными приложениями Windows 95 ещё требует проверки на целевой системе.

## Замена оболочки Windows 95 и возврат

Откройте **правый щелчок по панели → Properties** либо
**рабочий стол → Explorer95 → Taskbar and Start Menu Properties**.
В секции Windows 95 system shell доступны:

- `Use Explorer95 as shell...` — копирует программу в каталог Windows как
  `EXPLR95.EXE`, сохраняет исходную настройку и устанавливает её в `[boot] shell=`.
- `Restore previous shell...` — возвращает точную сохранённую команду, включая
  аргументы. Остальные записи SYSTEM.INI остаются на месте.

Изменения действуют **после перезапуска Windows**. Текущий Explorer автоматически
не завершается. На других версиях Windows изменение загрузочной оболочки запрещено
самой программой; пользовательские настройки панели при этом доступны.

Перед первой сменой создаются файлы в каталоге Windows:

- `EX95BAK.INI` — полная исходная копия SYSTEM.INI;
- `EX95REC.INI` — исходная команда оболочки и путь установленной программы.

Не удаляйте их до восстановления штатной оболочки. Программа отказывается заменять
неизвестную существующую резервную копию и не перезаписывает оболочку, которую после
неё выбрала другая программа.

**Восстановление из DOS:** откройте SYSTEM.INI в каталоге установленной Windows
(например, `C:\WIN95` или `C:\WINDOWS`) и восстановите только строку `shell=` в секции
`[boot]`, взяв её исходное значение из EX95BAK.INI. Для обычной установки это
`shell=Explorer.exe`. Сохраните файл и запустите Windows снова. Не восстанавливайте
весь старый INI поверх более новых системных настроек без необходимости.

## Управление и настройки

- Start → `Exit`: закрыть Explorer95; для основной оболочки требуется подтверждение.
- Правый щелчок по свободной области панели: блокировка, автоскрытие, размер,
  положение, быстрый запуск, свойства и показ/восстановление рабочего стола.
- Сняв блокировку, тяните свободную область панели к нужному краю экрана;
  её внутреннюю границу можно тянуть для изменения толщины.
- Часы: двойной щелчок открывает системные настройки даты и времени.
- Значок Explorer95 в трее: настройки панели; правый щелчок — меню панели.
- Win+D и Ctrl+Esc работают, если эти сочетания доступны для регистрации.
- В файловом окне: Enter/Go — перейти; F5 — обновить; Alt+Up — вверх;
  Ctrl+L/F4 — адрес; Enter/двойной щелчок в списке — открыть объект.
- Пути с пробелами в Run заключайте в кавычки:
  `"C:\Program Files\Example\app.exe" argument`.
- В свойствах панели можно очистить историю программ и открыть папку Quick Launch.

Настройки по умолчанию лежат в `Explorer95\Explorer95.ini` внутри папки данных
пользователя, возвращённой Shell32; рядом находится папка `Quick Launch`.
Для отдельного профиля можно указать существующий каталог:

```text
explorer95.exe --settings="C:\EX95\Explorer95.ini"
```

## Сборка и проверки

Нужны GNU Make и 32-битный MinGW-w64 GCC (`gcc-mingw-w64-i686` на Debian/Ubuntu).
Python 3 нужен для проверки структуры EXE.

```sh
make check
# Или, если компилятор имеет суффикс -win32:
make check CC=i686-w64-mingw32-gcc-win32
```

Результат: `build/explorer95.exe`. Это PE32 для x86/i386 с Windows GUI/OS 4.0,
ANSI Win32 API и без MSVCRT/UCRT, .NET или движка тем. Shell32 и COM используются
через базовые интерфейсы; IE4 и Active Desktop не требуются.

В текущей облачной среде:

```sh
make check CC=/workspace/.explorer95-tools/root/usr/bin/i686-w64-mingw32-gcc-win32
```

В одноразовом Windows/Wine-окружении с поддержкой 32-битных приложений и дисплеем:

```sh
make smoke
```

Тест создаёт свой профиль и временные файлы, проверяет навигацию, рабочий стол,
Run, историю, быстрый запуск, группировку, уведомления трея, Show Desktop,
сохранение настроек, края экрана и автоскрытие. Backend установки/восстановления
оболочки проверяется **только на временных INI-файлах**, не на системном SYSTEM.INI.
Перед тестом закройте другие экземпляры Explorer95.

Если хост не исполняет 32-битные процессы, доступна тестовая сборка того же кода:

```sh
make ui64-smoke WINE=wine64
```

Для неё нужен `x86_64-w64-mingw32-gcc`. Файлы из `build/ui64` не предназначены для
Windows 95. Проверка пакетов трея под Wine проверяет регистрацию и callbacks;
передача HICON между процессами Wine отличается от Windows 95 и отдельно не
подтверждена этим тестом.

`make check` проверяет заголовки PE и разрешённый список импортов; это не доказательство
полной совместимости с Windows 95. GitHub Actions собирает основной EXE и проверяет
импорты; отдельный job Source UI smoke проверяет исходный код под Wine64. Workflow
для тегов `v*` создаёт предварительный релиз с EXE, ZIP и SHA256.

Остаются ограничения: файловые окна пока не повторяют все операции и панели XP;
группировка выполняется по процессу; не реализованы полный shell DDE/appbar-сервер
для сторонних панелей, расширенные уведомления и все внутренние протоколы Explorer.
Новый вариант замены оболочки необходимо проверить при реальной загрузке Win95 RTM/OSR2.
